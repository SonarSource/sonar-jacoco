### 質問やフィードバックはありますか？

フィードバックを送るには（機能リクエストやバグ報告など）、[SonarQubeコミュニティフォーラム](https://community.sonarsource.com/)をご利用ください。言語とタグ「jacoco」、プラグインのバージョン、およびSonarQubeのバージョンを必ず明記してください。

プラグインの使い方について質問がある場合（そして[ガイド](https://community.sonarsource.com/t/coverage-test-data-importing-jacoco-coverage-report-in-xml-format/12151)では解決できない場合）、こちらのコミュニティフォーラムの利用も推奨します。
