### ¿Cómo usarlo?

Eche un vistazo a la guía [para importar el informe de cobertura de JaCoCo en formato XML](https://community.sonarsource.com/t/coverage-test-data-importing-jacoco-coverage-report-in-xml-format/12151).

### ¿Tiene preguntas o comentarios?

Para enviar comentarios (solicitar una función nueva, informar sobre un error, etc.), utilice el [Foro Comunitario de SonarQube](https://community.sonarsource.com/). No olvide especificar el idioma y etiquetar con ‘jacoco’, la versión del plugin y la versión de SonarQube.

Si tiene dudas sobre cómo utilizar el plugin (y la [guía](https://community.sonarsource.com/t/coverage-test-data-importing-jacoco-coverage-report-in-xml-format/12151) no le ayuda), también le animamos a utilizar el foro comunitario.
