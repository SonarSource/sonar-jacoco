# SonarQube JaCoCo plugin

This repository contains the SonarQube integration for importing Java code-coverage reports generated by JaCoCo. Continue to the usage guide below to import a coverage report.

To learn more about the SonarQube product family, visit the [Sonar website](https://www.sonarsource.com/products/sonarqube/).

<!-- sonar-marketing:end -->

### How to use?

Have a look at [importing JaCoCo coverage report in XML format](https://community.sonarsource.com/t/coverage-test-data-importing-jacoco-coverage-report-in-xml-format/12151) guide.
